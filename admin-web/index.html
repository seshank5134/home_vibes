☁️ Cloud Computing & Applications Architecture

HomeVibes demonstrates an enterprise cloud-native food delivery system utilizing managed Platform-as-a-Service (Supabase PaaS) on PostgreSQL 15, Firebase Cloud Messaging (FCM), Google Maps APIs, and mobile cloud clients.

1. PostgreSQL & RLS (PaaS)

PostgreSQL 15 manages 10 relational tables. Role-Based Access Control is enforced at the database kernel level through Row Level Security (RLS) policies for Customers, Drivers, and Admins.

2. Realtime WebSockets

Supabase Realtime listens to PostgreSQL Change Data Capture (WAL logs). Status changes and GPS breadcrumbs are broadcast immediately to subscribed web and mobile clients without polling.

3. Serverless Edge Functions

Deno / TypeScript serverless functions execute trusted operations (price re-verification, order creation, driver dispatch validation) eliminating client privilege escalation vulnerabilities.

4. Mobile GPS Streaming

The Flutter Android application captures live location fixes and transmits throttled coordinates every 5-10 seconds to the driver_locations table during active transit.
