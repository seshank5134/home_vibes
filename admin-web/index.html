Cloud Computing & Distributed Applications Architecture

HomeVibes implements a cloud-native DIY food delivery architecture utilizing managed Database-as-a-Service (Supabase PostgreSQL 15), Serverless Edge Functions, Realtime WebSocket telemetry, and mobile cloud clients.

1. Managed PostgreSQL & RLS

PostgreSQL 15 provides relational integrity across 10 tables. Row-Level Security policies isolate customer orders, driver GPS telemetry, and administrative dispatch records at the DB kernel level.

2. Realtime WebSocket Streaming

Supabase Realtime listens to WAL change-data-capture. Driver GPS breadcrumbs and order dispatch transitions are pushed instantly to web and mobile subscribers with sub-100ms latency.

3. Serverless Edge Functions

Deno serverless compute modules handle trusted business validation: re-calculating order price sums, validating driver dispatch state machines, and generating notifications.

4. Multi-Platform Driver Client

The Flutter Android application continuously publishes driver position fixes to driver_locations and synchronizes active order pick-up and delivery status changes.
